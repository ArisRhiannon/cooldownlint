# Contributing to cooldownlint

Thanks for helping! cooldownlint stays small: no runtime dependencies, no network access during scans, deterministic output.

## Dev setup

```bash
git clone https://github.com/ArisRhiannon/cooldownlint && cd cooldownlint
npm test
```

## Pull requests

- Add a test for every behaviour change (one true positive and one near-miss for new rules).
- Update README and CHANGELOG.
- Short imperative commit subjects.
